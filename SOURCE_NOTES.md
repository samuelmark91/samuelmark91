# Source provenance

This project adapts Mark Samuel's supplied coursework, not a completed live-business engagement. Original uploads remain unchanged. No YouTube code or authentication material was copied into this package.

| Source | Role |
|---|---|
| MarkSamuel_Week4.R | Churn classification: logistic regression, LDA, lasso and KNN |
| MarkSamuel_Week5.R | Churn classification: CART, bagging, random forest and C5.0 |

The new project uses logistic regression, CART and random forest with a shared design. Changes to feature selection, folds and evaluation mean that previous coursework scores are not carried forward.

The mlc_churn data are supplied by the modeldata package and documented as artificial. The new pipeline loads the package dataset at execution time and records its snapshot and fingerprint. It includes no newly invented customer observations.
